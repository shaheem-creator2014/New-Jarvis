# JARVIS

Personal local AI assistant for Shaheem, with a knowledge graph, optional Ollama chat/voice, approved tools, read-only integrations and explicit memory.

## Run on Windows

Install Python 3.11 or newer, then open the repository in VS Code and run:

```powershell
cd jarvis
py -3 run.py
```

The browser opens the local dashboard. Demo mode is enabled by default; no packages or API keys are needed for the demo. AI chat and live integrations need separate configuration.

See [the complete setup and privacy guide](jarvis/README.md) for optional services, tests, security boundaries and unverified live/hardware capabilities.
